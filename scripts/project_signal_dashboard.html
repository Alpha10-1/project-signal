Data confidence by source

Share of records in each dataset carrying at least one unresolved exception flag. Use this before trusting a KPI drawn from a low-confidence source.
Reading this dashboard — every KPI is computed only from fields that survived cleaning (parsed dates, canonical equipment codes, converted units). Records still carrying an open exception are included in totals but counted in that metric's confidence score, so a metric can look precise and still deserve a second look. Full exception detail lives in the companion triage queue.
